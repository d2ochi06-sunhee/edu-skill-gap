# edu-skill-gap

> **수도권 대학평생교육원 기반 기본직무 마이크로디그리 설계 및 하이브리드 재교육 모델 EDA 대시보드**

---

## 📌 프로젝트 소개
수도권 성인학습자 및 중소·중견기업 재직자의 대다수를 차지하는 **5대 기본 직무(경영·기획, 디지털 마케팅, 회계·세무, 유통·물류, 인사·노무)**를 중심으로, **수도권 대학부설 평생교육원** 및 **국가평생교육진흥원 K-MOOC** 인프라를 연계한 **마이크로디그리(소단위 학위) 설계**와 **온·오프라인 하이브리드 재교육 모델**을 탐색하는 EDA 프로젝트입니다.

---

## 📊 활용 공공데이터 API (3종)
1. **한국산업인력공단 - NCS 교육과정**
   - 5대 기본직무(사무, 마케팅, 회계, 유통, 인사)의 표준 능력단위 및 훈련시간(30~50H) 체계 분석
2. **국가평생교육진흥원 - K-MOOC 강좌정보 API**
   - 수도권 주요 대학(서울대, 연세대, 고려대, 한양대 등) 평생교육원 개설 강좌 자원 현황 및 학점은행제 인정 여부, 교육 공백(Gap) 분석
3. **한국산업인력공단 - 원격훈련모니터링시스템 통계정보**
   - 성인학습자 원격훈련 이탈 임계선(40시간 한계선) 도출 및 **온라인 60%(평일 야간) + 오프라인 평생교육원 실습 40%(격주 토요일)** 하이브리드 모델 입증

## 🚀 빠른 시작 가이드 (uv 사용)

본 프로젝트는 고속 패키지 관리자 **`uv`**를 표준으로 사용합니다.

### 1. 환경변수 설정
`.env.example` 파일을 복사하여 `.env`를 생성하고 공공데이터포털 인증키를 등록합니다.
```bash
cp .env.example .env
```

### 2. 가상환경 생성 및 패키지 설치
```bash
# 가상환경 생성
uv venv --python 3.12 .venv

# 의존성 설치
uv pip install -r requirements.txt
```

### 3. EDA 대시보드 실행
```bash
# uv 가상환경으로 대시보드 구동
uv run streamlit run src/dashboard/app.py
```
브라우저에서 `http://localhost:8501`로 접속하여 확인합니다.
