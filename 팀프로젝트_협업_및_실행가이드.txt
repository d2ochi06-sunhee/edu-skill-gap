이 문서는 안티그래비티(Antigravity IDE), 깃(Git), 터미널이 낯선 팀원들을 위해 아주 쉽게 작성된 설명서입니다.
처음부터 차근차근 따라 해보세요!


--------------------------------------------------------------------------------
0. 안티그래비티(Antigravity)에서 "터미널" 열고 입력하는 법 (필독!)
--------------------------------------------------------------------------------
안티그래비티 화면에는 2개의 입력 공간이 있습니다:
  ① AI 채팅창: "대시보드 수정해줘"처럼 AI에게 말을 거는 곳
  ② 터미널(Terminal) 창: 컴퓨터에게 직접 깃(Git) 명령어를 내리는 곳 (★우리가 쓸 곳!)

[터미널 창 여는 방법]
1. 안티그래비티 화면 맨 위 상단 메뉴에서 [Terminal] -> [New Terminal] 을 클릭합니다.
   (단축키: 키보드에서 [Ctrl] 키를 누른 채 숫자 1 왼쪽의 [~] 물결/백틱 키 누르기)
2. 화면 맨 아래쪽에 검은색(또는 파란색) 터미널 창이 짠! 하고 나타납니다.
3. 맨 아랫줄에 'PS D:\...>' 처럼 폴더 경로가 보이고 커서가 깜빡거립니다.

[명령어 입력하는 방법]
1. 검은색 터미널 창 안을 마우스로 한 번 '콕' 클릭합니다. (커서가 활성화됩니다)
2. 아래 가이드에 적힌 명령어를 복사한 후, 터미널 창에서 [마우스 우클릭] 또는 [Ctrl + V] 로 붙여넣습니다.
3. 키보드의 [엔터(Enter)] 키를 누르면 컴퓨터가 명령을 실행합니다!
4. 글자들이 주르륵 지나가고 다시 맨 아랫줄에 'PS D:\...>'가 뜨면 실행이 완료된 것입니다.


--------------------------------------------------------------------------------
★ [가장 중요한 기본 규칙] 컴퓨터마다 저장 폴더가 달라도 되나요?
--------------------------------------------------------------------------------
Q: 저는 바탕화면에 저장했고, 팀원은 D드라이브에 저장했는데 괜찮나요?
A: 네! 100% 정상 작동합니다! 
   우리 프로젝트 코드는 특정 컴퓨터 주소를 쓰지 않고 '상대 경로'로 스스로 찾아가도록 
   설계되어 있어서, 컴퓨터의 어느 폴더(바탕화면, C드라이브, D드라이브 등)에 받아도 상관없습니다.

👉 단! 딱 1가지 규칙만 꼭 지켜주세요!
   안티그래비티에서 프로젝트를 열 때는 반드시:
   화면 맨 위 메뉴 [File (파일)] -> [Open Folder (폴더 열기)] 를 눌러서
   깃허브에서 다운받은 [edu-skill-gap] 폴더 자체를 선택해서 열어야 합니다!
   (터미널 맨 끝 글자가 '...edu-skill-gap>' 상태여야 모든 명령어가 잘 작동합니다.)


--------------------------------------------------------------------------------
1. 프로젝트 처음 시작할 때 딱 1번만 하는 작업 (초기 세팅)
--------------------------------------------------------------------------------

[1단계] 코드 내 컴퓨터로 가져오기 (클론)
터미널 창에 아래 한 줄을 치고 엔터:
git clone https://github.com/kimsaemi/edu-skill-gap.git
cd edu-skill-gap

[2단계] 비밀 API 키 파일(.env) 만들기
- 보안상 API 키는 깃허브에 올라가지 않습니다. 각자 컴퓨터에 만들어 주어야 합니다.
- 터미널 창에 아래 명령을 치면 템플릿 파일이 복사되어 .env 파일이 생깁니다:
  (윈도우 기준)
  copy .env.example .env

- 생성된 [.env] 파일을 메모장이나 코드 편집기로 열고, 카톡으로 전달받은 
  공공데이터 API 인증키를 따옴표 안에 붙여넣고 저장(Ctrl + S)합니다.

[3단계] 프로그램 설치하기 (uv 사용 시 - 5초 만에 완료)
터미널 창에 아래 2줄을 순서대로 치고 엔터:
uv venv --python 3.12 .venv
uv pip install -r requirements.txt


--------------------------------------------------------------------------------
2. 매일 작업할 때 이것만 외우세요! (하루 작업 3단계 루틴)
--------------------------------------------------------------------------------

★ 1단계: 컴퓨터 켜고 작업 시작할 때 (가장 중요!)
다른 팀원이 어제 올린 최신 코드를 내 컴퓨터로 먼저 다운로드받고 시작합니다.
터미널 창에 아래 2줄을 순서대로 입력하고 엔터를 치세요:

git pull origin main
uv run streamlit run src/dashboard/app.py

👉 엔터를 치면 잠시 후 인터넷 브라우저 창이 자동으로 열리면서 대시보드가 뜹니다!
   (주소: http://localhost:8501)


★ 2단계: 작업하는 동안
- 파이썬 파일(src/ 폴더 안의 파일들)을 수정하고 저장(Ctrl + S)합니다.
- 브라우저 대시보드(http://localhost:8501)를 열어 새로고침(F5)하면 내가 수정한 내용이 바로 보입니다.
- 대시보드를 끄고 싶을 때는 터미널 창에서 [Ctrl] + [C] 를 누르면 꺼집니다.


★ 3단계: 오늘의 작업을 마치고 깃허브에 올릴 때
작업이 끝났으면 팀원들이 볼 수 있도록 깃허브에 올려줍니다.
터미널 창에 아래 3줄을 한 줄씩 치고 엔터를 누르세요:

git add .
git commit -m "오늘 작업한 내용을 짧게 적기 (예: 마케팅 차트 수정)"
git push origin main

👉 여기까지 하면 내 작업물이 깃허브 웹사이트에 안전하게 올라갑니다!


--------------------------------------------------------------------------------
3. 자주 묻는 질문 (FAQ)
--------------------------------------------------------------------------------

Q1. 깃허브에 push(올리기)를 했는데 빨간 글씨로 에러(rejected)가 떠요!
A: 내가 작업하는 동안 다른 팀원이 먼저 깃허브에 올려서 그렇습니다. 당황하지 마세요!
   터미널 창에 아래처럼 먼저 당겨받고 다시 올리면 해결됩니다:
   git pull origin main
   git push origin main

Q2. API 키가 적힌 .env 파일이 깃허브에 안 올라가는데 괜찮은 건가요?
A: 네, 완벽히 정상입니다! API 키는 개인 비밀번호와 같아서 깃허브에 올라가면 해킹 위험이 있습니다.
   프로젝트 설정(.gitignore)에서 자동으로 숨기도록 처리해 두었으니 안심하세요.

Q3. 브라우저 대시보드에서 타겟이나 직무를 바꿨는데 저장이 따로 필요한가요?
A: 아닙니다! 드롭다운 메뉴에서 항목을 선택하는 순간 0.1초 만에 화면 전체가 실시간으로 자동 새로고침됩니다. 별도의 '확인/조회' 버튼을 누르실 필요가 없습니다.
